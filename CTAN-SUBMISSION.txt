Summary:
Typeset Classical Chinese texts with Japanese Kanbun reading annotations.

Description:
gckanbun provides commands for Japanese-style Kanbun typesetting, including
ruby, group ruby, okurigana, return marks, re-reading annotations, special
compound return marks, local vertical typesetting, and aligned Chinese-poetry
layouts. LuaLaTeX is recommended; basic (u)pLaTeX support is also provided.

Announcement:
Version 2.6.0 makes command chaining whitespace-insensitive: a space, line
break, or comment between cooperating commands (such as a ruby or group ruby
followed by okurigana or a return mark) no longer breaks the lookahead or
inserts spurious glue, so spaced and adjacent input produce identical layout.
Invalid "intrusion" option values now raise a package error instead of being
silently accepted. The distribution adds a whitespace regression matrix and a
LuaLaTeX-only "make check" release gate, alongside the existing horizontal,
vertical, and upLaTeX matrices.
