gckanbun v2.6.1

The gckanbun package provides commands for typesetting Classical Chinese
(Kanbun) with Japanese reading marks, okurigana, ruby, re-reading annotations,
special return marks, and Chinese-poetry layouts.

Version 2.6.1 is an internal consistency fix with no change to typeset output.
The rule for inserting the boundary ghost character after ruby and okurigana is
now uniform across all four annotation commands: no ghost is emitted when a
cooperating command follows, and a ghost is emitted before any other following
character. Three edge-test cases that applied "intrusion" where it had no
overhang to work with, making the return mark collide with the next character,
have been removed.
